Forward Auth Settings

Note: the reverse proxy in front of Jellyfin must strip these headers from any request it did not itself authenticate, or a client could set it directly.

The header the reverse proxy sets to the authenticated username, for example X-authentik-username.
The header the reverse proxy sets to the user's groups, separated by a pipe, for example X-authentik-groups.
Members of this group are made Jellyfin administrators at login, and non-members lose administrator rights. The match is case sensitive. Leave empty to manage administrators manually.
